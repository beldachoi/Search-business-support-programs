# 지원사업 서칭 에이전트

## 하는 일
소상공인·중소기업 지원사업 공고를 매일 수집하고, 설정해 둔 업체 기준으로 등급(◎/○/△/×)을 판정해 일일 리포트로 남기는 Claude 자동화 작업 폴더입니다. 실행 절차는 `CLAUDE.md`에 있습니다.

## 준비물
- Claude 데스크톱 앱 (켜져 있어야 내장 브라우저로 공고 사이트를 순회할 수 있음)
- 이 폴더를 작업 폴더로 연결한 Claude 대화 또는 예약 작업
- Node.js와 `docx` 패키지 (리포트를 워드로 변환할 때: `npm install docx`)
- Gmail 연결 (선택: 리포트 메일 발송을 쓸 때)

## 넣을 자료
`00_설정/`의 6개 파일을 본인 상황에 맞게 채웁니다.

| 파일 | 내용 |
|---|---|
| `업체프로필.md` | 업종·소재지·업력·직원수·매출 등 자격 판정의 근거 |
| `키워드.md` | 핵심·확장·제외 검색 키워드 |
| `검색소스.md` | 순회할 사이트 목록 |
| `알림설정.md` | 리포트 수신 주소, 파일 이름 규칙 |
| `자금전략.md` | 시설자금·보증 등 자금 트랙 계획 |
| `판정기준.md` | 등급 정의와 자동 판정 규칙 |

## 시키는 말 한 줄
```
CLAUDE.md를 읽고 오늘 지원사업 서칭을 실행해줘.
```

## 결과가 쌓이는 곳
| 폴더 | 쌓이는 것 |
|---|---|
| `01_일일리포트/` | 날짜별 리포트 (`.md` 정본, `.docx` 사본) |
| `02_공고DB/` | 수집 공고 마스터 목록(`공고목록.csv`), 마감 캘린더 |
| `03_원문보관/` | 날짜별 주요 공고 원문 요약 |
| `04_실행로그/` | 실행 기록, 접속이 안 되는 사이트 기록 |

`05_템플릿/`은 리포트 양식, `06_도구/`는 워드 변환 스크립트입니다.
