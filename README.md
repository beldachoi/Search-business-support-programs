# 지원사업 서칭 에이전트

매일 새로 올라온 소상공인·중소기업 지원사업 공고를 사이트별로 훑어 수집하고, 내 업체 조건에 맞는지 ◎/○/△/× 로 판정해 일일 리포트로 남기는 Claude 작업 폴더입니다. 실행 절차의 정본은 `CLAUDE.md`입니다.

## 준비물
- Claude Code 또는 Claude 데스크톱 앱 (공고 사이트를 직접 열어 보는 내장 브라우저 사용)
- Node.js와 `docx` 패키지 (리포트를 워드 파일로 바꿀 때: `npm install docx`)
- Gmail 연동 (리포트 메일 발송을 쓸 때만)
- 매일 자동 실행하려면 컴퓨터와 앱이 켜져 있어야 합니다.

## 넣을 자료 (`00_설정/` 폴더의 파일을 본인 것으로 채우기)
- `업체프로필.md` : 업종, 소재지, 업력, 직원 수, 매출 등 자격 판정 기준
- `키워드.md` : 핵심·확장·제외 검색 키워드
- `검색소스.md` : 순회할 사이트 목록
- `판정기준.md` : 등급 정의와 마감 임박 기준
- `자금전략.md` : 시설자금·보증 등 자금 계획 (필요할 때)
- `알림설정.md` : 리포트를 받을 이메일 주소와 파일 이름 규칙

## 시키는 말 (한 줄)
> CLAUDE.md를 먼저 끝까지 읽고, 그 절차대로 오늘자 지원사업 서칭을 수행해줘.

## 결과가 쌓이는 곳
- `01_일일리포트/` : 날짜별 리포트 (`YYYY-MM-DD_지원사업_리포트.md`, 워드 변환본)
- `02_공고DB/` : 전체 공고 목록(`공고목록.csv`)과 마감 캘린더
- `03_원문보관/` : 날짜별 주요 공고 요약
- `04_실행로그/` : 실행 기록과 접속 불가 사이트 점검 기록

공고 신청·제출·로그인·결제는 하지 않고, 조사와 보고까지만 합니다.
