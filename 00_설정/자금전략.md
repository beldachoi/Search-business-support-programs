# 자금 전략 (별도 트랙으로 매일 감시)

> 최종 갱신: 2026-11-25. 사용자가 계획을 바꾸면 이 파일을 먼저 고친다. 금액·시기는 사용자가 말한 값이며 에이전트가 추정하지 않는다.

## 현재 상황
- 2027년 공장 토지 매입 예정, 소요 35~40억 원(시설자금).
- 신용보증기금 보증 7억 원 이용 중. 2027년부터 원금 상환 시작.
- 법인, 특허 5건 보유, 직수출 계획 없음(간접 수출).

## 검토 중인 선택지 (사용자 검토 사항, 결론 아님)
1. 신보 보증 증액
2. 다른 정책자금으로 대환·전환 (중진공, 경기도 육성자금 등)
3. 특허 5건 기반 기술평가 → 기술보증기금(기보)으로 이전

## 감시 대상과 판정 시 볼 것
| 후보 | 볼 것 |
|---|---|
| 경기도 중소기업육성자금(시설자금) | 공장부지 매입 포함 여부, 기업당 한도(2026년은 이자지원 최대 30억), 접수기간, 2027년 1차 공고 시작일 |
| 중진공 정책자금(시설자금) | 토지매입 가능 여부, 한도, 금리, 2027년 융자계획 공고, 정책자금 내비게이션 결과 |
| 기술보증기금 | 기술평가보증 우대 상품, 특허 보유 시 평가 가점, 보증 한도, 갈아타기 조건 |
| 신용보증기금 | 증액·특례보증 공고, 한도 |
| 화성시 동반성장 협력사업 | 시설자금 대상 아님. 한도 소진·대상 아님이면 경기도 육성자금 안내 |
| 이차보전(시중은행) | 토지매입 대출에 붙는 이자 지원 |

## 판정 규칙
- 토지 매입·시설자금 사용 가능 + 신청시기 2027년 이내 → ○ 이상 (자금 트랙 표시).
- 운전자금 전용, 창업 초기 전용 → × 또는 △.
- 한도·금리·보증 조건은 공식 공고 원문에서만 확정한다. 확인 못하면 `확인 필요`.
- 기존 보증 이용 중이라는 사실이 중복지원 제한에 걸리는지 공고별로 확인한다.
- 조사와 보고까지만 한다. 대출·보증 신청과 상담 예약은 하지 않는다.

## 사용자에게 아직 확인 못한 것
- 토지 매입 시기(월), 자부담 가능 비율, 담보로 제공할 자산, 현재 은행 거래 구조.
