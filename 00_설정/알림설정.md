# 알림·발송 설정

> 사용자가 바꾸라고 하면 이 파일만 고친다.

## 리포트 이메일
- 받는 사람: beldachoi@gmail.com (사용자 본인. 다른 주소로는 보내지 않는다)
- 시점: 일일 리포트(.md)와 최종 워드 문서가 완성된 직후, 실행마다 1통
- 첨부: 최종 워드 문서 1개
- 제목: `[지원사업 리포트] YYYY-MM-DD 신규 n건 (◎a·○b), 마감 임박 m건`
- 본문(텍스트): ◎/○ 공고 제목과 마감일 한 줄씩, 마감 임박 건, 수집 실패 소스, 폴더 위치. 10줄 안쪽.

## 파일 이름
- 마크다운(정본): `01_일일리포트/YYYY-MM-DD_지원사업_리포트.md`
- 워드(변환본): `01_일일리포트/YYYY-MM-DD_지원사업_리포트.docx`
- 워드(최종 발송본): `01_일일리포트/YYYY-MM-DD_지원사업_최종리포트_HHMM.docx` (HHMM은 완성 시각 KST). 같은 날 여러 번 실행해도 덮어쓰지 않고 시각으로 구분한다. 이메일에는 이 파일을 첨부한다.
